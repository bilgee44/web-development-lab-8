# Лаб 8 — Bootstrap ба Tailwind CSS

- `bootstrap/index.html` — Bootstrap 5.3.3 (CDN), `data-bs-theme`, `.btn-brand` (`brand.css`)
- `tailwind/index.html` — Tailwind v4, `@custom-variant dark`, `@theme { --color-brand }`

## Tailwind build
```
npm install
npm run tw:build    # tailwind/dist/output.css (minify)
npm run tw:watch
```
